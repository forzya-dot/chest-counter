# Счётчик сундуков

Маленькая программа для Windows 10/11, которая считает открытые сундуки в Fortnite.

Считаете вы сами: открыли сундук — нажали **F9**. Программа ведёт счёт матча, статистику по дням и на секунду показывает картинку со счётом поверх игры.

**Про безопасность.** Программа не подключается к интернету и никак не взаимодействует с игрой: не читает её память, экран или трафик и ничего в неё не внедряет. Это обычный счётчик с глобальными горячими клавишами Windows, все данные лежат только на вашем компьютере.

---

## Как скачать и запустить

1. Откройте ссылку на страницу **Releases**, которую вам прислали, и скачайте файл `ChestCounter.exe`.
2. Положите файл в удобное место, например в папку `Документы\ChestCounter`. Устанавливать ничего не нужно, Python тоже не нужен.
3. Запустите `ChestCounter.exe` двойным щелчком. Первый запуск занимает несколько секунд.

Чтобы обновить программу, просто замените файл на новый. Статистика при этом сохранится.

### Windows пишет «Система Windows защитила ваш компьютер»

Это фильтр SmartScreen. Он показывает такое окно для любой программы, у которой нет платной цифровой подписи. На вирус это не указывает.

1. В синем окне нажмите **«Подробнее»**.
2. Внизу появится кнопка **«Выполнить в любом случае»** — нажмите её.

Предупреждение показывается один раз. Если кнопки «Подробнее» нет:

1. Щёлкните по файлу правой кнопкой мыши и выберите **«Свойства»**.
2. Внизу вкладки «Общие» поставьте галочку **«Разблокировать»** и нажмите «ОК».
3. Запустите файл снова.

Если файл удалил антивирус, восстановите его из карантина и добавьте в исключения. Антивирусы иногда ошибочно ругаются на программы, собранные в один `.exe`.

## Как пользоваться

### Горячие клавиши

Работают всегда, в том числе когда игра развёрнута на весь экран.

| Клавиша | Действие |
|---|---|
| **F9** | +1 сундук |
| **Ctrl+F9** | отменить последний (−1, но не ниже нуля) |
| **F10** | завершить матч: результат уходит в статистику, счётчик матча обнуляется |

После каждого нажатия звучит короткий сигнал: высокий для +1, низкий для отмены, двойной для конца матча.

Пока программа запущена, игра эти клавиши не получает. Проверьте, что в настройках Fortnite на F9, Ctrl+F9 и F10 ничего не назначено, или поменяйте клавиши в `config.json`.

### Главное окно

- Крупная цифра — сундуки в текущем матче.
- Ниже — сколько открыто за сегодня и за всё время.
- Кнопки «+1 сундук», «Отменить» и «Завершить матч» делают то же, что клавиши.

Крестик не закрывает программу, а прячет окно в трей (значки возле часов). Клавиши продолжают работать.

Матч, в котором не открыто ни одного сундука, в статистику не записывается.

### Значок в трее

Щелчок левой кнопкой открывает окно. Правая кнопка открывает меню:

- **Открыть окно**
- **Статистика** — таблица по дням, всего матчей, среднее и рекорд за матч
- **Экспорт в CSV** — сохранить все матчи в файл, который открывается в Excel
- **Автозапуск с Windows** — включить или выключить запуск вместе с компьютером (программа стартует сразу в трей)
- **Выход** — полностью закрыть программу

Если значка не видно, нажмите стрелочку «^» слева от часов. Значок можно перетащить оттуда на панель задач.

### Картинка поверх игры

При каждом +1 в углу экрана на полторы секунды появляется картинка с текущим счётом. Она не мешает играть: не забирает фокус у игры и пропускает клики мыши.

Если картинки поверх игры не видно, откройте в Fortnite «Настройки → Изображение → Режим окна» и выберите **«Оконный полноэкранный»**. В «чистом» полноэкранном режиме Windows иногда не рисует другие окна поверх игры.

## Настройки

Настройки лежат в файле `config.json`. Чтобы его открыть, нажмите **Win+R**, вставьте `%APPDATA%\ChestCounter` и нажмите Enter. Откройте файл Блокнотом, поменяйте нужное, сохраните и перезапустите программу (трей → «Выход», затем запустите снова).

```json
{
  "hotkeys": {
    "add": "F9",
    "undo": "Ctrl+F9",
    "end_match": "F10"
  },
  "sound": {
    "enabled": true
  },
  "overlay": {
    "enabled": true,
    "image": "",
    "size": 160,
    "duration_ms": 1500,
    "fade_ms": 400,
    "anchor": "top-right",
    "offset_x": 40,
    "offset_y": 120,
    "show_count": true
  },
  "save_empty_matches": false
}
```

| Настройка | Что значит |
|---|---|
| `hotkeys` | Клавиши. Примеры: `"F6"`, `"Ctrl+F9"`, `"Alt+Shift+K"`, `"Num5"`. Модификаторы: `Ctrl`, `Alt`, `Shift`, `Win`. |
| `sound.enabled` | `false` — без звуковых сигналов. |
| `overlay.enabled` | `false` — не показывать картинку. |
| `overlay.image` | Путь к своей картинке PNG, например `"C:/Pictures/my.png"` (косые черты — прямые). Пусто — встроенная картинка. |
| `overlay.size` | Размер картинки в пикселях. |
| `overlay.duration_ms` | Сколько картинка видна, в миллисекундах (1500 = 1,5 секунды). |
| `overlay.fade_ms` | Сколько из этого времени она плавно исчезает. |
| `overlay.anchor` | Место на экране: `top-left`, `top-center`, `top-right`, `center`, `bottom-left`, `bottom-center`, `bottom-right`. |
| `overlay.offset_x`, `overlay.offset_y` | Отступы от выбранного края экрана в пикселях. |
| `overlay.show_count` | `false` — картинка без числа. |
| `save_empty_matches` | `true` — записывать в статистику и матчи без сундуков. |

Если файл испортился, просто удалите его. При следующем запуске программа создаст новый с настройками по умолчанию.

В той же папке лежат `stats.db` (статистика) и `app.log` (журнал ошибок). Чтобы перенести статистику на другой компьютер, скопируйте `stats.db`.

## Если что-то не так

**«Клавиша F9 уже занята другой программой».** Эту клавишу раньше захватила другая программа: запись экрана, оверлей видеокарты, Discord и подобные. Закройте её или назначьте другую клавишу в `config.json`. Кнопки в окне работают в любом случае.

**Клавиши не срабатывают в игре, хотя на рабочем столе работают.** Попробуйте запустить `ChestCounter.exe` от имени администратора: правая кнопка → «Запуск от имени администратора». Это может помочь, если сама игра запущена с правами администратора.

**«Счётчик сундуков уже запущен».** Программа уже работает, её значок в трее возле часов.

**Нет звука.** Проверьте громкость в микшере Windows и что `sound.enabled` равно `true`.

**Удалить программу.** Выключите автозапуск в меню трея, выйдите из программы, удалите `ChestCounter.exe` и папку `%APPDATA%\ChestCounter`.

## Для разработчика

Логика (`chest_counter/core`) не зависит от Windows и тестируется где угодно. Код в `chest_counter/win` работает только в Windows и проверяется в GitHub Actions.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt -r requirements-dev.txt
.venv/bin/python -m pytest
.venv/bin/python main.py
```

На Mac открывается только главное окно, без клавиш, трея, звука и оверлея.

**Сборка.** Workflow `.github/workflows/build.yml` на `windows-latest` запускает тесты, собирает `ChestCounter.exe` через PyInstaller, прогоняет его с флагом `--self-test` и выкладывает как artifact `ChestCounter` (вкладка Actions → нужный запуск → Artifacts).

Artifact скачивается только с входом в GitHub и хранится 90 дней. Чтобы друг мог скачать файл без аккаунта, поставьте тег, и workflow создаст релиз с `.exe`:

```bash
git tag v1.0.0
git push origin v1.0.0
```

Скачивание без аккаунта работает только для публичного репозитория.

**Замена картинки.** Положите свой PNG в `assets/chest.png`. Скрипт убирает белый фон и заодно делает значок `assets/icon.ico`:

```bash
.venv/bin/python tools/prepare_image.py исходник.png assets/chest.png
```
